### 二、 Docker 快速部署编排 (`docker-compose.yml`)

集成了支持向量索引的 PG16 镜像及会话缓存 Redis：

YAML

```
version: '3.8'

services:
  postgres:
    image: pgvector/pgvector:pg16
    container_name: ai_interview_pg
    restart: always
    environment:
      POSTGRES_DB: ai_interview_platform
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: SecurePassword2026!
      PGDATA: /var/lib/postgresql/data/pgdata
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres -d ai_interview_platform"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: ai_interview_redis
    restart: always
    ports:
      - "6379:6379"
    volumes:
      - redisdata:/data

volumes:
  pgdata:
  redisdata:
```

### 三、 完整 PostgreSQL 数据库表结构 (`init.sql`)

包含：教研组织架构、用户体系、向量化题库、会话过程状态、逐题诊断及综合复盘。

SQL

```
-- 启用必备扩展
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "vector";

-- 1. 班级信息表 (教研管理核心)
CREATE TABLE cohorts (
    id BIGSERIAL PRIMARY KEY,
    cohort_name VARCHAR(128) NOT NULL,
    track VARCHAR(64) NOT NULL DEFAULT 'AI_APP_DEV',
    instructor_id BIGINT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE,
    status VARCHAR(32) NOT NULL DEFAULT 'ACTIVE', -- ACTIVE, GRADUATED, ARCHIVED
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 2. 用户主表
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(64) UNIQUE NOT NULL,
    nickname VARCHAR(64) NOT NULL DEFAULT '',
    password_hash VARCHAR(255) NOT NULL,
    email VARCHAR(128) DEFAULT '',
    role VARCHAR(32) NOT NULL DEFAULT 'STUDENT', -- 'STUDENT', 'INSTRUCTOR', 'ADMIN'
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 3. 班级成员映射表
CREATE TABLE cohort_members (
    id BIGSERIAL PRIMARY KEY,
    cohort_id BIGINT NOT NULL REFERENCES cohorts(id) ON DELETE CASCADE,
    student_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    student_no VARCHAR(64),
    joined_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(cohort_id, student_id)
);

-- 4. 简历解析数据表
CREATE TABLE resumes (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    file_url VARCHAR(512) NOT NULL,
    raw_text TEXT NOT NULL,
    parsed_skills JSONB DEFAULT '[]'::jsonb,
    parsed_projects JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 5. AI应用开发专业题库 (集成 PGVector 向量检索)
CREATE TABLE question_bank (
    id BIGSERIAL PRIMARY KEY,
    job_track VARCHAR(64) NOT NULL,
    difficulty VARCHAR(32) NOT NULL DEFAULT 'MEDIUM',
    category VARCHAR(64) NOT NULL, -- 如 Prompt, Chunking, ToolCall, CostOpt
    title VARCHAR(255) NOT NULL,
    standard_eval_points JSONB NOT NULL,
    default_follow_ups JSONB,
    embedding vector(1536), -- 匹配 text-embedding-3-small 或 bge-large
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_qbank_embedding ON question_bank USING hnsw (embedding vector_cosine_ops);

-- 6. 面试会话表 (挂载班级ID以供教师端下钻分析)
CREATE TABLE interview_sessions (
    id BIGSERIAL PRIMARY KEY,
    session_id UUID UNIQUE NOT NULL DEFAULT uuid_generate_v4(),
    user_id BIGINT NOT NULL REFERENCES users(id),
    cohort_id BIGINT REFERENCES cohorts(id),
    resume_id BIGINT REFERENCES resumes(id),
    job_track VARCHAR(64) NOT NULL,
    interviewer_style VARCHAR(32) NOT NULL DEFAULT 'HARDCORE', -- GUIDING, HARDCORE, BUSINESS
    status VARCHAR(32) NOT NULL DEFAULT 'INIT', -- INIT, IN_PROGRESS, ANALYZING, COMPLETED, ABORTED
    target_question_count INT NOT NULL DEFAULT 5,
    current_turn_index INT NOT NULL DEFAULT 0,
    session_metadata JSONB DEFAULT '{}'::jsonb, -- 存储 LangGraph Checkpoint
    started_at TIMESTAMPTZ,
    ended_at TIMESTAMPTZ,
    duration_seconds INT GENERATED ALWAYS AS (EXTRACT(EPOCH FROM (ended_at - started_at))) STORED,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 7. 逐轮面试交互明细表 (含追问与录音链路)
CREATE TABLE interview_turns (
    id BIGSERIAL PRIMARY KEY,
    session_id UUID NOT NULL REFERENCES interview_sessions(session_id) ON DELETE CASCADE,
    turn_no INT NOT NULL,
    is_follow_up BOOLEAN NOT NULL DEFAULT FALSE,
    parent_turn_id BIGINT REFERENCES interview_turns(id) ON DELETE SET NULL,
    question_text TEXT NOT NULL,
    user_answer_audio_url VARCHAR(512),
    user_answer_text TEXT,
    audio_duration_seconds INT DEFAULT 0,
    flaws_and_gaps JSONB DEFAULT '[]'::jsonb, -- 识别出的缺陷要点
    turn_score INT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 8. 面试综合复盘诊断报告表
CREATE TABLE interview_reports (
    id BIGSERIAL PRIMARY KEY,
    session_id UUID UNIQUE NOT NULL REFERENCES interview_sessions(session_id) ON DELETE CASCADE,
    user_id BIGINT NOT NULL REFERENCES users(id),
    cohort_id BIGINT REFERENCES cohorts(id),
    overall_score INT NOT NULL,
    score_engineering_depth INT NOT NULL DEFAULT 0,
    score_system_design INT NOT NULL DEFAULT 0,
    score_star_structure INT NOT NULL DEFAULT 0,
    score_stress_handling INT NOT NULL DEFAULT 0,
    summary_critique TEXT NOT NULL,
    recommended_lessons JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 索引构建
CREATE INDEX idx_sessions_cohort_status ON interview_sessions(cohort_id, status);
CREATE INDEX idx_reports_cohort_score ON interview_reports(cohort_id, overall_score);
CREATE INDEX idx_turns_session_no ON interview_turns(session_id, turn_no);
CREATE INDEX idx_turns_flaws_gin ON interview_turns USING gin (flaws_and_gaps);
```

### 四、 核心接口设计

#### 1. 学员端核心接口

- **创建面试考场：** `POST /api/v1/interviews`
  - **请求体：** `{"cohort_id": 1, "resume_id": 101, "job_track": "AI_AGENT_DEV", "interviewer_style": "HARDCORE"}`
  - **响应：** 返回 `session_id` 与 WebSocket 连线地址。
- **双工考场交互：** `WSS /ws/interviews/{session_id}`
  - **客户端上行：**
    - 发送二进制数据块：16kHz 16bit Mono PCM 音频流。
    - 控制事件：`{"event": "USER_SPEECH_STOP", "payload": {"duration_ms": 12500}}`。
  - **服务端下行：**
    - 实时识别回显：`{"type": "ASR_INTERIM_TRANSCRIPTION", "payload": {"text": "在设计混合检索时..."}}`。
    - 考官回答 Token 流：`{"type": "INTERVIEWER_TOKEN_STREAM", "payload": {"chunk": "请问你的重排...", "is_follow_up": true}}`。
    - 考官语音切片：`{"type": "INTERVIEWER_AUDIO_STREAM", "payload": {"audio_base64": "..."}}`。
- **获取个人诊断报告：** `GET /api/v1/interviews/{session_id}/report`
  - 返回四大维度量化得分、改进建议以及每一轮的 STAR 标准表达重构对照。

#### 2. 教师端核心教研与看板接口

- **班级学情概览与缺陷统计：** `GET /api/v1/teacher/cohorts/{cohort_id}/analytics`
  - **响应结构：**

### 五、 教师端高频业务统计 SQL

可直接写入后端数据访问层（Repository），充分利用 PG 原生特性的高效统计查询：

##### 1. 查询班级学员战报与排名榜

SQL

```
SELECT 
    u.id AS student_id,
    cm.student_no,
    u.nickname AS student_name,
    COUNT(r.id) AS total_interviews,
    ROUND(AVG(r.overall_score), 1) AS avg_score,
    MAX(r.overall_score) AS max_score,
    MAX(r.created_at) AS last_interview_at
FROM cohort_members cm
JOIN users u ON cm.student_id = u.id
LEFT JOIN interview_reports r ON r.user_id = u.id AND r.cohort_id = cm.cohort_id
WHERE cm.cohort_id = :cohort_id
GROUP BY u.id, cm.student_no, u.nickname
ORDER BY avg_score DESC NULLS LAST;
```

##### 2. 统计班级高频失分技术盲区（使用 JSONB 横向展开聚合）

SQL

```
SELECT 
    f.flaw_item::text AS common_flaw,
    COUNT(*) AS hit_times
FROM interview_turns t
JOIN interview_sessions s ON t.session_id = s.session_id
CROSS JOIN LATERAL jsonb_array_elements_text(t.flaws_and_gaps) AS f(flaw_item)
WHERE s.cohort_id = :cohort_id
GROUP BY common_flaw
ORDER BY hit_times DESC
LIMIT 10;
```
